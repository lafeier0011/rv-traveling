# RV Traveling · 房车看世界

一款以房车旅行为主题的休闲桌面游戏，陪你看风景、听环境音，安排专注与休息。

## Windows 下载

[下载 Windows x64 预览版](https://github.com/lafeier0011/rv-traveling/releases/download/v0.1.0-preview.1/rv-traveling-0.1.0-preview.1-windows-x64.zip)

[全部版本与更新说明](https://github.com/lafeier0011/rv-traveling/releases)

下载约 251 MiB，解压后约 321 MiB。完整解压 ZIP 后，双击 `rv-world.exe` 即可启动，无需安装 Godot。请保持 `rv-world.pck` 与程序位于同一个文件夹。

## 当前内容

- 通过旅行手札切换地点。
- 调整时段、天气、环境声音与语言。
- 时钟、闹钟和番茄钟，以及桌面组件模式。

关闭游戏后，闹钟和番茄钟不会继续运行。当前预览版尚未提供在线更新与地图资源包下载功能，程序尚未进行数字签名。

本仓库用于发布游戏介绍和 Windows 下载包。第三方素材说明与署名见下载包内的 `credits` 文件夹。
